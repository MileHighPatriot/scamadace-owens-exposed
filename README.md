# Scamdace Owens Exposed

Public static website cataloguing Candace Owens’s claims about the Charlie Kirk assassination (Sept 10, 2025 – July 25, 2026) and the public evidence that dismantles them.

**Author:** MileHigh Patriot ([@America1st5280](https://x.com/America1st5280))

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Homepage |
| `claims.html` | Searchable claim catalog |
| `claim.html?id=…` | Deep-dive: claim → verdict → evidence stack |
| `facts.html` | Public record baseline (+ July 2026 hearing) |
| `earnings.html` | Estimated revenue from Kirk-assassination content |
| `toolkit.html` | Retired redirect → claim catalog |
| `submit.html` | Submit claims (primary links required) |
| `about.html` | Mission / author |
| `corrections.html` | Corrections policy |
| `sitemap.xml` / `robots.txt` | Crawler discovery |

## Content

Claims live in `js/claims-data.js` (50+ claim objects). Add new objects there to expand the catalog. Each claim: primary sources → tiered evidence → related claims.
